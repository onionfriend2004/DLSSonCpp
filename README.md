# HW1 — Graph Compressor

Сериализация/десериализация неориентированного взвешенного графа без
кратных рёбер в компактный бинарный формат.

## Запуск

```bash
make
./run -s -i input.tsv -o graph.bin    # сериализация
./run -d -i graph.bin -o output.tsv   # десериализация
```

Формат TSV: `u\tv\tw` на строку (`u, v` — id вершин, `w` — вес ребра).
`output.tsv` может отличаться от `input.tsv` только порядком строк и порядком
`u`/`v` в строке.

## Идея сжатия

- **Индексация вершин** — id хранятся один раз в отсортированном списке,
  рёбра ссылаются на номера в нём.
- **Дельта-кодирование** — id и соседи хранятся как разности соседних
  значений после сортировки, а не как абсолютные числа.
- **Порядок рёбер не хранится** — он не важен по условию, это даёт основную
  экономию (`log2(M!)` бит).

## Алгоритмы

**Range coder** (`range_coder.hpp`) — бинарное адаптивное арифметическое
кодирование, схема из LZMA[^1]: сообщение кодируется как сужающийся отрезок
`[low, low+range)`, вероятность каждого бита адаптируется на лету. Взята
только сама схема интервального кодирования, без словарного сжатия LZ77.

**Exp-Golomb кодирование** (`num_model.hpp`) — отдельная техника для
целых чисел[^2], надстроенная поверх range coder'а: число `x = value+1`
кодируется как унарная длина `floor(log2 x)` + биты мантиссы (старшие —
адаптивно, младшие — сырыми). Используется для всех разностей и степеней
вершин.

[^1]: https://neerc.ifmo.ru/wiki/index.php?title=Алгоритм_LZMA
[^2]: https://en.wikipedia.org/wiki/Exponential-Golomb_coding
